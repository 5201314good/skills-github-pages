# GitHub Pages 自定义域名 DNS检查失败踩坑记录

今天尝试给我的 GitHub Pages 博客绑定自定义域名 `www.langccwu.com`，遇到报错：
> DNS检查失败
> www.langccwu.com 及其备用名称配置不正确，无法检索该域的 DNS 记录。(InvalidDNSError)

## 报错原因
GitHub 会去查询你域名的DNS解析记录，如果没有配置正确的CNAME或者A记录，就会直接报这个错误。

## 两种解决思路
### 方案一（新手推荐，无报错）
放弃自定义域名，直接使用 GitHub 自带域名：
`https://5201314good.github.io`
不需要配置DNS，自带HTTPS，提交代码后就能正常访问，不会出现DNS校验失败。

### 方案二（坚持使用自定义域名）
1. 进入域名解析后台，添加一条CNAME记录
    - 主机记录：`www`
    - 记录类型：`CNAME`
    - 记录值：`5201314good.github.io`
2. 如果使用 Cloudflare，这条记录的代理模式必须改成灰色（DNS Only），橙色代理会校验失败
3. DNS解析不是实时生效，需要等待十几分钟到24小时，可以用 dnschecker.org 查看全球解析状态
4. 解析生效后，回到GitHub Pages页面重新填写域名，再检查一次

## 我的心得
一开始以为填完域名就能马上用，忽略了DNS解析这一步。
如果只是想先把博客跑起来，先用默认的 `github.io` 域名是最省心的，等熟悉了再折腾自定义域名。
